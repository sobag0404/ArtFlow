# ArtFlow

Массовая сборка инфографики на Windows. Работает локально, без аккаунта и установки Python.

[**Скачать установщик ArtFlow**](https://github.com/sobag0404/ArtFlow/releases/latest/download/ArtFlow-Setup.exe)

Эта ссылка всегда скачивает последнюю опубликованную версию. Для обновления запустите новый установщик: он заменит программу и сохранит партии.

[Что нового](https://github.com/sobag0404/ArtFlow/releases/latest) · [История версий](CHANGELOG.md)

В программе есть команда «Проверить обновления»: по нажатию она показывает последнюю версию и изменения и открывает скачивание в браузере. Изображения и партии обрабатываются локально.

Разметка нескольких PNG-слайдов, наклонные области, пакетная сборка TIFF-артов, индивидуальные правки и экспорт подтверждённых комплектов.

Цель совместимости — Windows 10/11 x64. Текущая сборка проверена на Windows 11; отдельная проверка Windows 10 пока не проведена. Установщик пока без цифровой подписи издателя, поэтому Windows может показать предупреждение об неизвестном издателе.

В этом репозитории публикуются установщики и заметки о выпусках.
